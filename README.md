# billet

「気持ちを贈ろう。」——ふたり（Koki / Eri）で券を発行し合い、受け取り・使用・履歴を管理する発券アプリ（PWA）。
券の種類（終電券・4時券・7時券・バリア券・バリア貫通券）とレア度（NORMAL / RARE / SSR）を選んで相手に贈れる。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | エントリ。React 18 と Firebase（compat）を CDN から読み込む。読み込み失敗時の診断表示つき |
| `app.js` | アプリ本体（JSX を事前にプレーン JS へ変換したもの。変換前のソースはこのリポジトリにない） |
| `firebase-config.js` | Firebase プロジェクトの設定値。未設定ならブラウザ内だけの一時保存で動く |
| `sw.js` / `manifest.json` / `icon-*.png` | PWA（ホーム画面に追加）用 |

データは Firestore の `okuriken_storage` コレクションに保存される。

## ローカルで動かす

```sh
python3 -m http.server 8000
# http://localhost:8000/index.html を開く
```

## 注意

- `firebase-config.js` の `apiKey` などはブラウザに配る前提の公開値で、秘密情報ではない。
  データを守るのは Firestore の「ルール」なので、テストモードのまま長期運用しないこと
- テストモードは 30 日で期限切れになり、アプリが読み書きできなくなる（下記「うまくいかないときは」参照）

# 公開する手順

このフォルダの中身をそのまま使えば、誰でもアクセスできるWebサイトとして
公開でき、スマホの「ホーム画面に追加」でアプリのように使えます。
むずかしい操作（コマンド入力やGitHubなど）は一切不要です。

大まかな流れ：
**① データの保存先を用意する（Firebase）→ ② サイトを公開する（Netlify）→ ③ ホーム画面に追加する**

所要時間の目安：15〜20分

---

## ① Firebaseの準備（複数人でチケットを共有するため）

1. https://console.firebase.google.com/ を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 好きな名前（例：okuriken）を入力 → 作成
   （Google アナリティクスは「無効にする」でOK）
3. 左メニューの「構築」→「Firestore Database」→「データベースの作成」
4. ロケーションはそのままで次へ。**「テストモードで開始」を選択**して有効にする
   - テストモードは30日間だれでも読み書きできる設定です。個人・友人内で使う
     分には問題ありませんが、期限が切れると自動でアクセスできなくなるので、
     長く使いたい場合は30日以内にFirebaseの「ルール」タブで期限を延長してください
5. 画面左上の歯車アイコン →「プロジェクトの設定」→ 下にスクロールして
   「マイアプリ」→「</> (ウェブ)」のアイコンをクリック
6. アプリのニックネームを適当に入力して「アプリを登録」
7. 表示された `firebaseConfig = { ... }` の中身をコピー

8. このフォルダの **`firebase-config.js`** をテキストエディタで開き、
   コピーした内容で中身を置き換える：

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "okuriken-xxxx.firebaseapp.com",
  projectId: "okuriken-xxxx",
  storageBucket: "okuriken-xxxx.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:xxxxxxxx",
};
```

9. 保存する

※ この設定をしなくてもサイト自体は動きますが、その場合「自分のブラウザだけの
一時保存」になり、相手にチケットが届きません（画面上部に赤い注意バナーが出ます）。

---

## ② サイトを公開する（Netlify Drop）

アカウント登録すら不要な、一番簡単な方法です。

1. https://app.netlify.com/drop を開く
2. このフォルダ（リポジトリの中身ごと）を、そのままページにドラッグ＆ドロップ
3. 数十秒でアップロードが終わると、`https://ランダムな文字列.netlify.app` という
   URLが発行されます。これが公開URLです

**あとで編集し直したくなったら？**
無料のNetlifyアカウントを作ってからドロップすると、同じサイトを何度でも
上書き公開できます（アカウントなしだと毎回新しいURLになります）。
Claudeでファイルを修正したら、フォルダをまるごと再ドロップしてください。

---

## ③ ホーム画面に追加する（アプリ化）

**iPhone（Safari）:**
公開URLをSafariで開く →共有ボタン（□に↑）→「ホーム画面に追加」

**Android（Chrome）:**
公開URLをChromeで開く → 右上の「⋮」→「ホーム画面に追加」

これで、アイコンをタップするだけでアプリのように起動できます。

---

## 使い方（相手に伝えること）

1. 公開したURLを相手に送る（LINEなど）
2. 相手は最初に自分の名前を入力（毎回同じ名前を使うこと）
3. あなたが「窓口1 発券」で相手の名前を宛先にして発行すると、
   相手の「窓口2 受け取った券」に届く（数秒おきに自動更新されます）

---

## うまくいかないときは

- チケットが届かない → 双方とも `firebase-config.js` を設定し、同じ
  Firebaseプロジェクトを指しているサイトを開いているか確認
- 画面上部に赤いバナーが出ている → Firebase未設定です。①をやり直してください
- 30日経って動かなくなった → FirebaseコンソールのFirestore「ルール」タブで
  期限を延長するか、ルールを見直してください
